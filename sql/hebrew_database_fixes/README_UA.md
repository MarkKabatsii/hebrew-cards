# Перевірена база слів та інструменти механіка

Переглянуто всі **436 карток** із `sql/Supabase Snippet Untitled query.csv`. Виправлено **142 картки**, зроблено **174 зміни полів**. Оригінальний CSV збережено без змін. Додано окремий словник із **60 інструментів**.

## Файли

- `words_corrected.csv` — повний виправлений знімок 436 наявних карток, з усіма початковими колонками. Це знімок для перегляду/резервування, а не файл для імпорту через сайт.
- `01_fix_words.sql` — точкове оновлення наявних карток у Supabase.
- `02_add_mechanics.sql` — додавання 60 нових карток головному власнику словника з цього експорту.
- `mechanics_import.json` — альтернативне додавання інструментів через сторінку імпорту сайту.
- `mechanics.csv` — таблиця інструментів для перегляду; стандартний CSV з комами сайт безпосередньо не розбирає.
- `changes.csv` — кожна зміна: ID, поле, попереднє та нове значення, тип виправлення.
- `audit_all_cards.csv` — результат перегляду кожної з 436 карток.
- `03_rollback_words.sql` — повернення виправлених наявних карток до стану експорту; нові інструменти не видаляє.
- `build.py` — відтворення файлів та структурні перевірки, лише стандартна бібліотека Python.

## Транскрипція та межі перевірки

Транскрипція — українське наближення сучасної ізраїльської вимови, не IPA. «Г» передає ה, «ґ» — звук ג, «х» — ח або כ без даґеша. Апостроф у «лір'от» / «ір'ур» допомагає розділити голосні. Наголос систематично не позначено. М'який знак у деяких знайомих запозиченнях залишено як наближення, він не є твердженням про фонетичну м'якість івритського ל. Початкові правильні картки з нікудом збережено; нові інструменти записано переважно без нікуда, як у робочих каталогах.

Дієслова подано в інфінітиві, прикметники — переважно в чоловічій однині. Слова можуть мати додаткові значення залежно від контексту. У робочому словнику позначено розмовні назви «בוקסה», «פלייר», «בוקים»; місцеві назви інструментів можуть відрізнятися між майстернями. Перегляд усіх рядків виконано вручну; зовнішні джерела використано для вибіркової перевірки складних форм і термінів, а не для незалежної словникової сертифікації кожної картки.

## Як застосувати

1. Зробіть актуальний експорт `public.words` у Supabase перед запуском.
2. У SQL Editor виконайте **весь** `01_fix_words.sql`. Він працює транзакційно, перевіряє ID, власника й початковий вміст кожної змінюваної картки. Якщо вміст відрізняється від експорту та від виправленого стану, операція зупиниться. Поля прогресу не входять у порівняння й не оновлюються. Повторний запуск пропускає вже виправлені картки.
3. Виконайте **весь** `02_add_mechanics.sql`. Власник явно заданий: `78a03550-1895-4551-b50d-1ade76f86516`, як у 427 картках вихідного CSV. Інші користувачі не отримають інструменти автоматично. Запит перевіряє наявні картки за власником, категорією, розділом та івритом і пропускає їх. На час транзакції блокує паралельні записи в таблицю; читання залишається доступним. Конкретний унікальний індекс не потрібний. Повторний запуск не створить дублікати.
4. Оновіть сайт зі зміненим `js/taxonomy.js`, щоб категорія «Майстерня» та розділ «Інструменти механіка» з'явилися в меню. Код підготовлено локально; публікацію на Netlify не виконано.

Альтернатива кроку 3: після оновлення сайту увійдіть потрібним користувачем, відкрийте «Імпорт» і вставте **весь вміст** `mechanics_import.json`. Це додає картки поточному користувачу, не використовує UUID із SQL. Оберіть один спосіб додавання інструментів.

SQL не запускався на живій базі: тут перевірено структуру CSV, незмінність усіх службових полів, відсутність сторонніх літер у полі івриту, відсутність латинських/арабських символів у транскрипції та конфліктів унікальних ключів. Усі 60 інструментів також успішно пройшли справжній парсер імпорту застосунку. PostgreSQL у локальному середовищі недоступний, тому виконання SQL на сервері не перевірене.

Після оновлення має залишитися 436 початкових карток і додатися 60 нових; всього 496 для всієї таблиці, якщо від експорту не було інших змін. У головного власника — 487, у другого — 9. У новій категорії головного власника — 61 картка: 60 інструментів та перенесена гайка.

## Відкат наявних карток

`03_rollback_words.sql` повертає лише поля словника в 142 змінених картках. Він перевіряє поточний стан та не стирає прогрес навчання. Перед відкатом знову експортуйте поточну базу. Додані інструменти залишаються; автоматичного видалення цих карток немає. Якщо після оновлення картки редагували вручну або з'явився конфлікт ключів, транзакція зупиниться.
