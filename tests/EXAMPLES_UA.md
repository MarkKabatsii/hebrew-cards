# Приклади на звороті карток

## Реалізація

`Store.withExamples()` спочатку використовує чинний `Store.all()`, потім завантажує `word_examples` пакетами по 200 ID через той самий клієнт і сесію. SELECT явно перелічує поля з описаної схеми, має `status=approved` та пагінацію. У клієнті повторно перевіряються статус, тип порядкового номера, заповненість текстових полів і належність до завантажених ID; результат сортується, повтори порядку прибираються, показуються максимум два приклади.

Якщо приклади недоступні, слова залишаються доступними, показується загальне повідомлення без тексту SQL/помилки сервера. Перевертання, розгортання й оцінювання не завантажують приклади повторно. `words`, прогрес та алгоритм повторень не змінюються.

Основна картка тепер має окрему кнопку на передній стороні; зворот не вкладений у кнопку. Натискання на текст або вільну область будь-якої сторони перевертає картку. Native `details/summary` «Ще один приклад» розгортає речення без перевороту. Під час збереження й переходу до наступного слова переворот заблоковано. Кнопку «Повернути до слова» видалено; зворот має фокус і повертається до слова натисканням Enter або пробілу. Розмір обох сторін визначає CSS grid, а не фіксована висота. Текст переноситься; іврит має `lang=he`, `dir=rtl`, збільшений line-height, українські тексти — `lang=uk`, `dir=ltr`. Рендер використовує лише `textContent` і DOM-елементи.

На прихованій стороні встановлюються `inert` і `aria-hidden=true`. Фокус перед перевертанням переноситься на зворот картки або кнопку передньої сторони. У квізі прихований зворот також виключений із accessibility tree до відкриття після неправильної відповіді. Квіз зберігає попередню поведінку й не завантажує речення.

## Перевірки

```bash
npm test
python3 data/hebrew-examples/validate_examples.py
python3 data/hebrew-examples/validate_reviewed_examples.py
node tests/examples.browser.cjs
```

Історичний звіт попередньої роботи (не поточний запуск; examples.test.cjs і Python-валідаторів у цьому checkout немає): 51 автоматична перевірка пройшла: 42 попередні та 9 нових. Нові охоплюють 0/1/2 прикладів, сортування, чернетки, неправильні типи, bigint ID як рядки, безпечний текстовий рендер, запити пакетами, fallback та inert/focus.

Браузерний тест використовує Node.js 22+ з native WebSocket і локальний headless Chrome. За іншого шляху до браузера задайте `CHROME_PATH`. Він створює тимчасові копії справжніх HTML-сторінок, вилучає зовнішні скрипти/шрифти й справжню конфігурацію, підставляє локальний Supabase. Запитів до production немає. Знімки й JSON-звіт записуються до тимчасової папки, шлях показується після успіху.

Перевірено Chrome на 320/390/768 px для кожного з 0/1/2 прикладів, включно з навмисно довгими текстами. Немає горизонтального переповнення й обрізання звороту. Перевірені native disclosure, фокус, `inert`, accessibility tree перед перевертанням, збій прикладів, очищення прикладів після оцінки й переходу до наступного слова та прихований правильний переклад у квізі. Знімки 320 і 768 px також переглянуті візуально. Приклади тут штучні й використовуються для перевірки розмітки, а не мовного контенту.

## Що ще перевірити після ручного імпорту

1. Увійти на сайт із власним акаунтом і відкрити слово зі схваленими прикладами. У Network має бути пакетне завантаження; перевертання не створює новий запит до `word_examples`.
2. Для слова без approved-прикладів не має бути порожнього заголовка. Draft та приклади іншого власника недоступні.
3. Установити блокування запиту `word_examples` в DevTools: слова мають залишитися доступними, а повідомлення — загальним.
4. Перевірити реальні шрифти, Safari/VoiceOver та клавіатуру: прихована сторона не озвучується, друге речення відкривається без перевертання.

Схему сервера, FK, RLS та відповіді справжнього клієнта з акаунтом користувача агент не перевіряв: локально доступні опис завдання та експорти. Підготовлено необов’язковий read-only `00_inspect_examples_schema.sql`, але він теж не запускався. SQL імпорту/схвалення підготовлений і перевірений на узгодженість даних; PostgreSQL не виконував його.

API: [Supabase select](https://supabase.com/docs/reference/javascript/select).
